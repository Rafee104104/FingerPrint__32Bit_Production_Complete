# Button Icons

Put PNG icons in this folder with these exact file names:

- `connect.png` - Connect button
- `disconnect.png` - Disconnect button
- `insert-db.png` - Insert to DB button
- `load-attendance.png` - Load Attendance button
- `load-users.png` - Load Users button
- `export-csv.png` - Export CSV button

Recommended icon size: 32x32 PNG with transparent background. The app resizes them to 18x18 on the buttons.
